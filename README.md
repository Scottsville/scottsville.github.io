# The Bend in the River — Scottsville, Virginia

A website for Scottsville, VA. Hosted free on GitHub Pages.

Your site address will be: **https://scottsville.github.io**

---

## How to publish this site — step by step

### Step 1 — Create the repository

1. Sign in to github.com with your **Scottsville** account
2. Click the **+** icon in the top right corner
3. Select **New repository**
4. In the **Repository name** field, type exactly: `scottsville.github.io`
   - All lowercase
   - No spaces
5. Make sure **Public** is selected
6. Do NOT check "Add a README file" or anything else
7. Click **Create repository**

---

### Step 2 — Upload your files

After creating the repository you'll land on a page that says "Quick setup." Look for the small text that says **"uploading an existing file"** and click it.

You'll see a large dotted upload area.

**Before you drag anything in:** open the zip file on your computer and go *inside* the `scottsville-site` folder. You should see these files and folders:

```
index.html
history.html
today.html
issues.html
resources.html
README.md
css/
  style.css
```

**Select all of those** (not the scottsville-site folder itself, the contents inside it) and drag them into the GitHub upload area.

Wait for all files to finish uploading — you'll see them listed. Then scroll down and click **Commit changes**.

---

### Step 3 — Turn on GitHub Pages

1. In your repository, click **Settings** (the tab at the top)
2. In the left sidebar, click **Pages**
3. Under **Source**, make sure it says **Deploy from a branch**
4. Under **Branch**, select **main** from the dropdown, and **/ (root)** as the folder
5. Click **Save**

---

### Step 4 — Wait two minutes, then visit your site

Go to: **https://scottsville.github.io**

If you see a 404, wait another minute and refresh. It sometimes takes a few minutes the first time.

---

## How to edit the site later

1. Go to **github.com/Scottsville/scottsville.github.io**
2. Click the file you want to edit
3. Click the pencil icon
4. Make your changes
5. Click **Commit changes**

The site updates within seconds.

---

## Handing off to someone else

Go to your repository Settings, then Collaborators, then Add people and enter their GitHub username. To transfer full ownership: Settings, Danger Zone, Transfer repository.
